# 📍 Guide Me: Smart City Traveller App

**Guide Me** is an intelligent mobile application designed to enhance urban travel experiences by helping users easily explore and navigate their city. Built with a focus on smart city concepts, the app provides real-time location-based services, route guidance, and detailed information about nearby places.

## 🚀 Features

* 📌 **User Authentication**
  Secure login system to personalize user experience.

* 🗺️ **Interactive Map Integration**
  Uses OpenStreetMap to display real-time maps and nearby locations.

* 📍 **Current Location Detection**
  Automatically detects and shows the user's current position.

* 🏨 **Nearby Places Categorization**
  Explore nearby:

  * Hotels
  * Banks
  * ATMs
  * Restaurants
  * Other essential services

* 🧭 **Route Navigation**
  Get the best driving route from your current location to your selected destination using OSRM.

* 📏 **Distance & Travel Time**
  Displays estimated distance and travel time for better planning.

* 📝 **Place Details & Description**
  View detailed information about each place, including descriptions and images stored locally using SQLite.

## 🛠️ Technologies Used

* **Frontend:** Android (Java, XML)
* **Maps & Location:** OpenStreetMap, OSMDroid
* **Routing Engine:** OSRM API
* **Backend/Storage:** SQLite Database
* **API:** Overpass API (for fetching nearby places)

## 📱 How It Works

1. User logs into the app.
2. The app detects the current location.
3. Nearby places are fetched based on selected category.
4. Markers are displayed on the map.
5. Clicking a marker shows place details.
6. User can view route, distance, and travel time to the destination.

## 🎯 Objective

The main goal of **Guide Me** is to provide a simple, efficient, and smart solution for city travelers to navigate and explore urban areas without hassle.
