**Guide Me** is a mobile application designed to enhance urban travel experiences by helping users easily explore and navigate their city. It is built with a focus on smart city concepts, the app provides real-time location-based services, route guidance, and detailed information about nearby places.

## 🚀 Features

* 📌 **User Authentication** - Secure login system to personalize user experience.

* 🗺️ **Interactive Map Integration** - Uses OpenStreetMap to display real-time maps and nearby locations.

* 📍 **Current Location Detection** - Automatically detects and shows the user's current position.

* 🏨 **Nearby Places Categorization** - Explore nearby: Hotels/Resturants, Banks/ATMs, Hospitals & Tourist Attractions

* 🧭 **Route Navigation** - Get the best driving route from your current location to your selected destination using OSRM.

* 📝 **Place Details & Description** - View detailed information about each place, including descriptions and images stored locally using SQLite.

## 🛠️ Technologies Used

* **Frontend:** Android (Java, XML)
* **Maps & Location:** OpenStreetMap (OSM), OSMDroid
* **Routing Engine:** OSRM API
* **Backend/Storage:** SQLite Database
* **Authentication:** Firebase
* **Code Editor**: Android Studio

## 📱 How It Works

1. User logs into the app.
2. The app detects the current location.
3. Nearby places are fetched based on selected category.
4. Markers are displayed on the map.
5. Clicking a marker shows place details.
6. User can view route, distance, and driving time to the destination.

## 🎯 Objective

The main goal of **Guide Me** is to provide a simple, efficient, and smart solution for city travelers to navigate and explore urban areas without hassle.
